# Biblioteca Mário Rubens

Sistema de catalogação da biblioteca pessoal, com acesso restrito por login e senha.

- **Endereço:** https://marubensmude.github.io/biblioteca/
- **Dados e login:** Firebase (Google). Nenhum dado do acervo e nenhuma senha ficam neste repositório.
- **Logins autorizados:** definidos em `firebase-config.js` e em `firestore.rules`.

Ex libris · acervo pessoal.
